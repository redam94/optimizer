Core Pillars of the Framework

1. Model Abstraction Layer

A universal `AbstractModel` protocol decouples optimization logic from model implementation. Integrate any model—from legacy spreadsheets to cloud-native ML services—without refactoring.

2. Standardized Data Structures

Leverages Xarray to handle complex, multi-dimensional data (time, geography, channel, product), ensuring consistency, alignment, and validation across the entire system.

3. Pluggable Optimization Solvers

Choose the right tool for the job. The framework supports a variety of solvers, from deterministic methods like SciPy to advanced stochastic and gradient-free options like Optuna and Nevergrad.

The `AbstractModel` Protocol

Any object that conforms to our `AbstractModel` protocol can be plugged into the optimizer. This is achieved by defining a clear contract for prediction and contribution analysis, enforced through an abstract base class.


from abc import ABC, abstractmethod
import xarray as xr

class AbstractModel(ABC):
    @abstractmethod
    def predict(self, x: xr.Dataset) -> xr.DataArray:
        """Return predictions as an xarray DataArray."""
        pass

    @abstractmethod
    def contributions(self, x: xr.Dataset) -> xr.Dataset:
        """Return feature contributions as an xarray Dataset."""
        pass

Multi-dimensional Data with Xarray

We standardize all inputs into Xarray Datasets. This allows us to handle complex, labeled, multi-dimensional arrays, which is crucial for real-world marketing data that varies over time, geography, and product lines.


import xarray as xr

Pareto Frontier Analysis

For multi-objective problems, we generate a Pareto frontier—a set of optimal solutions where no objective can be improved without sacrificing another. This empowers executives to make informed trade-off decisions by visualizing the exact compromises between competing KPIs.
